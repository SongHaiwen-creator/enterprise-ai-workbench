## 检索与独立回答探针

两者通过现有Knowledge Base API独立测量，不与Agent Run互相替换。

| 指标 | 实测 | 分母与限制 |
|---|---|---|
| 检索请求成功 | 56/56 | 48有依据题 + 8无依据题 |
| Hit@3、Hit@5 | 各48/48（100%） | 有依据题；开发32/32、保留16/16 |
| 宏平均Document Recall@5 | 100% | 每题仅1份目标文档；12份短制度，每份仅1个片段 |
| 回答请求成功 | 52/56（92.9%） | 首次请求，4个HTTP 502保留为失败 |
| 目标文档引用覆盖 | 44/48（91.7%） | 错误仍在分母；开发28/32、保留16/16 |
| 已返回引用的目标文档精度 | 44/44（100%） | 不证明引用支持每项回答事实 |
| 无依据问题返回unsupported | 8/8（100%） | 均无答案和引用；样本很小 |
| 人工答案正确性复核 | 0/48 | 未测；不能把有引用或结构PASS算成答案正确 |

检索100%来自受控小语料和文档级指标。多道题共享制度，问题不是独立随机样本；
108题也不是企业流量分布。不能把该结果外推成真实知识库召回率，也不对其套用
真实业务准确率置信区间。原Feature009的200文档外部结果属于历史基线，本轮未重测。

## 问题与业务影响

已通过Feature018登记4个代表性Bad Case，均保持open、有不可变源结果与创建历史。
描述和可能原因是代理整理的待复核材料，没有改写评分或宣布已修复。

| 优先处理 | 证据 | 业务影响与下一步 |
|---|---|---|
| 回答引用契约 | 知识7个provider_contract；独立回答4个502。`qa_travel_04`的单独诊断返回两条E1引用，违反唯一编号校验 | 员工能检索到规则却拿不到答案。明确同一证据多事实的引用要求，保留严格验证；其余错误需逐题确认原因 |
| 安全咨询路由 | `qa_helpdesk_03`：“可以把验证码发给客服帮我重置吗？”被路由为tool_request | 制度咨询未获得基于证据的安全建议。确认咨询与实际操作的边界，修复后用新的独立场景测量 |
| 工具预期定义 | 保留集8题要求查询他人资料或修改报销/档案；Agent范围禁止这些请求，实际全部unsupported且adapter_executed=false | v1预期是tool_request再no_matching_tool，与范围定义可能冲突。不能当作越权执行；业务负责人确认拒绝层次后建立v2，不改v1刷分 |
| 拒答请求超时 | `refusal_missing_benefit_01`为case_timeout | 即使应当拒答也可能不可用。区分Provider调用超时与用例预算超时，保留错误并测量时延与波动 |

本轮没有调整模型、提示、权限或标准答案。首次契约错误后停止诊断，两次独立诊断
单独保留、不计分。记录显式诊断理由后只收齐剩余首次尝试；已成功/失败的题均未重试。
HTTP 502不暴露具体原因，不把所有502或provider_contract都归因于重复引用。

Agent执行跨2026-10-05与2026-10-09两次会话，中断后恢复相同后端提交
`8d9f3ea0f0f93dd70543056d011f24e99a8f5774`，配置探针仍匹配。
使用text-embedding-3-small（1536维）和既有gpt-5.6-terra/low配置、Top-K 5及固定预算。
成功的独立回答返回42,159输入、3,439输出、45,598总token；不包含Agent、索引/检索、
失败请求或两次诊断，不能当总成本。混合108题平均延迟8.99秒，包含策略模拟和错误，
不能当员工请求的响应SLA。
